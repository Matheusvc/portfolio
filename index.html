Sobre Mim

Quem está por
trás do código

Analista de Sistemas e Desenvolvedor Full-Stack com formação em Engenharia de Software pela Universidade CEUMA. Atuo para duas empresas entregando soluções que vão do levantamento de requisitos ao deploy em produção.

Minha stack combina Java + Spring Boot no back-end com React + TypeScript no front-end, sustentada por PostgreSQL e pipelines de deploy reais. Já entreguei plataformas de gestão com dashboards analíticos, chatbots com IA para atendimento automatizado e sistemas IoT com coleta de dados em tempo real.
